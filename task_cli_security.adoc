= Ändern Sie das Administratorkennwort von Deploy

Sie können das Kennwort für das Administratorkonto der virtuellen Maschine Deploy bei Bedarf über die Befehlszeile ändern.

.Schritte
. Melden Sie sich mit dem Administratorkonto bei der Deploy-Utility-CLI an.
. Ändern Sie das Passwort:
`password modify`
. Reagieren Sie auf alle Aufforderungen entsprechend Ihrer Umgebung.
