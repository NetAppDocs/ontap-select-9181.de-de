= Rufen Sie die Dokumentationsseite von ONTAP Select Deploy auf
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie müssen auf die ONTAP Select Deploy Online-Dokumentationsseite zugreifen, um die API-Dokumentation anzuzeigen und einen API-Aufruf manuell auszuführen.

.Bevor Sie beginnen
Sie benötigen Folgendes:

* IP-Adresse oder Domänenname der ONTAP Select Deploy-virtuellen Maschine
* Benutzername und Passwort für den Administrator


.Schritte
. Geben Sie die URL in Ihren Browser ein und drücken Sie die *Eingabetaste*:
+
`\https://<ip_address>/api/ui`

. Sign in mit dem Benutzernamen und dem Passwort des Administrators.


.Ergebnis
Die Webseite mit der Deploy-Dokumentation wird angezeigt, wobei die Aufrufe am unteren Rand der Seite nach Kategorien geordnet sind.
