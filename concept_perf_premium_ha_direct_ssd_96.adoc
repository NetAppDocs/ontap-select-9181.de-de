[[reference-platform]]
== Referenzplattform

ONTAP Select (Premium XL) Hardware (pro Knoten)

* FUJITSU PRIMERGY RX2540 M4:
+
** Intel(R) Xeon(R) Gold 6142b CPU mit 2,6 GHz
** 32 physische Kerne (16 x 2 Sockel), 64 logische
** 256 GB RAM
** Laufwerke pro Host: 24 960GB SSD
** ESXi 6.5U1




Client-Hardware

* 5 x NFSv3 IBM 3550m4 Clients


Konfigurationsinformationen

* SW RAID 1 x 9 + 2 RAID-DP (11 Laufwerke)
* 22+1 RAID-5 (RAID-0 in ONTAP) / RAID-Cache NVRAM
* Es werden keine Speichereffizienzfunktionen verwendet (Komprimierung, Deduplizierung, Snapshot-Kopien, SnapMirror und so weiter)


Die folgende Tabelle listet den Durchsatz auf, gemessen bei lesen/schreiben-Workloads auf einem hochverfügbaren (HA) Paar von ONTAP Select Nodes mit sowohl Software-RAID als auch Hardware-RAID. Die Leistungsmessungen wurden mit dem Lastgenerierungstool SIO durchgeführt.


NOTE: Diese Leistungszahlen basieren auf ONTAP Select 9.6.

*Leistungsergebnisse für einen einzelnen Knoten (Teil einer mittelgroßen Instanz mit vier Knoten) ONTAP Select Cluster auf einem direkt angeschlossenen SSD-Speicher (DAS) mit Software-RAID und Hardware-RAID*

|===


[[64k-sequential-read]]
=== 64K sequenzielles Lesen

Details:

* SIO direct I/O aktiviert
* 2 Knoten
* 2 x Daten-NIC pro Knoten
* 1 x Datenaggregat pro Knoten (2TB Hardware-RAID), (8TB Software-RAID)
* 64 SIO-Prozesse, 1 Thread pro Prozess
* 32 Volumes pro Knoten
* 1 x Dateien pro Prozessor; Dateien sind jeweils 12000MB groß




[[64k-sequential-write]]
=== 64K sequenzielles Schreiben

Details:

* SIO direct I/O aktiviert
* 2 Knoten
* 2 x Datennetzwerkschnittstellenkarten (NICs) pro Knoten
* 1 x Datenaggregat pro Knoten (2TB Hardware-RAID), (4TB Software-RAID)
* 128 SIO-Prozesse, 1 Thread pro Prozess
* Volumes pro Node: 32 (Hardware-RAID), 16 (Software-RAID)
* 1 x Dateien pro Prozessor; Dateien sind jeweils 30720MB groß
